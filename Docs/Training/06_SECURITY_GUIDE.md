# 🚪 Security Guide

> **Role:** Gate Security | **Access Level:** Gate Log Only

As Security, you verify dispatches leaving and entering the premises. This guide covers the Gate Log feature.

---

## 🎯 Your Responsibility

- Verify products and crates leaving the gate
- Verify products and crates returning to the gate
- Use the Gate Log to confirm dispatch information

**Note:** You do not see financial information (prices, revenue, commission). This is for security verification only.

---

## 🏠 Your Dashboard

When you log in, you'll see:

- Access to the Gate Log
- Today's summary (dispatches out, returned)

---

## 📋 Using the Gate Log

**Location:** Sales → **Gate Log**

### What the Gate Log Shows

The Gate Log displays dispatches **without financial information**:

| Column | What It Shows |
|--------|---------------|
| Dispatch # | The dispatch number |
| Salesperson | Who is taking/returning products |
| Date | Dispatch date |
| Time | When created |
| Products | What products are being dispatched |
| Quantities | How many of each product |
| Crates | Number of crates |
| Status | Dispatched / Returned |

### What You Do NOT See

- ❌ Revenue
- ❌ Commission
- ❌ Prices
- ❌ Financial totals

This is intentional - you only need to verify physical goods.

---

## ✅ Verifying Dispatches (Outgoing)

When a salesperson is leaving with products:

### Step 1: Get the Dispatch Number

1. Ask the salesperson for their **Dispatch Number** (e.g., DSP-20251222-001)

### Step 2: Find in Gate Log

2. Go to **Sales** → **Gate Log**
3. Find the dispatch by:
   - Dispatch number, OR
   - Salesperson name, OR
   - Today's date

### Step 3: Verify Products

4. Check that the **products match**:
   - Bread: X units?
   - Scones: X units?
   - KDF: X units?
   - Family Bread 800g: X units?

### Step 4: Verify Crates

5. Count the **crates** - should match the system

### Step 5: Allow Exit

6. If everything matches, allow them to leave
7. If there's a discrepancy, **stop and verify** with Dispatch Officer

---

## ✅ Verifying Returns (Incoming)

When a salesperson returns:

### Step 1: Identify the Salesperson

1. Note who is returning

### Step 2: Check Gate Log

2. Go to **Gate Log** and find their dispatch

### Step 3: Note What They Have

3. Observe:
   - Products being brought back
   - Number of crates
   
### Step 4: Allow Entry

4. Allow them to proceed to the Dispatch Officer
5. The Dispatch Officer will process the actual return

**Note:** You don't need to count exact returns - that's the Dispatch Officer's job. Just observe and note any obvious issues.

## 🔍 Filtering the Gate Log

### By Date

- **Today:** See only today's dispatches
- **Yesterday:** Check yesterday's records
- **Date range:** Select specific dates

### By Status

- **All:** Everything
- **Dispatched:** Only those currently out
- **Returned:** Only completed dispatches

### By Salesperson

- Search by salesperson name

## ⚠️ What to Watch For

### Red Flags

| Situation | Action |
|-----------|--------|
| No dispatch in system | Do not allow exit - verify with Dispatch |
| Quantities don't match | Stop and verify with Dispatch |
| Wrong products | Stop and verify |
| Missing crates | Note and report |
| Unknown person claiming dispatch | Verify identity |

### Report Issues

If something doesn't match:
1. **Stop** the salesperson
2. **Call** the Dispatch Officer
3. **Do not allow exit** until verified

## ❓ Common Questions

### Q: What if the dispatch isn't in the system?
Do not allow exit. Contact the Dispatch Officer immediately.

### Q: What if quantities don't match?
Stop the salesperson and verify with Dispatch Officer before allowing exit.

### Q: Do I process returns?
No, you just observe. The Dispatch Officer processes actual returns.

### Q: What if a salesperson argues with me?
Calmly explain you're following procedure. Call the Dispatch Officer or supervisor.

### Q: Can I see prices and commissions?
No, and you don't need to. Your job is physical verification only.

### Q: What if the system is down?
Contact your supervisor immediately. Do not allow dispatches without verification.
